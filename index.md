## 🆘 Troubleshooting

**The app window does not appear after I open it.**
Wait a few seconds, then check your taskbar. If it still does not show, close it and open it again from the folder where you saved it.

**My folder is empty in the app.**
Double-check that you selected the folder containing the files, not the parent folder above it. Use the browse button to re-select.

**A photo will not preview.**
Some very large images take a moment to load. Try clicking the item again, or open it in your usual photo viewer to confirm the file itself is fine.

**Search finds nothing.**
Clear the search box and try a shorter part of the name. Search matches file names, not the contents of every file.

**The app forgot my folders.**
If the app was moved to a different location after the first run, re-add your folders once. It will remember them again from that point on.

**I want to start over.**
Remove your folder entries from the app and add them fresh. Your actual files are untouched.
